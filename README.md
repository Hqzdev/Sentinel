# Sentinel

Desktop-приложение для мониторинга состояния компьютера с системой уведомлений через Telegram-бота.

## Описание проекта

Sentinel предназначен для отслеживания состояния Windows-компьютера в реальном времени. Приложение собирает системные метрики, отображает их в графическом интерфейсе, сохраняет историю показателей в SQLite и отправляет уведомления в Telegram при превышении заданных порогов.

Проект может использоваться для домашнего мониторинга компьютера, контроля рабочих станций и учебной демонстрации архитектуры desktop-приложений на C#.

## Основной функционал

- мониторинг загрузки CPU;
- мониторинг использования RAM;
- мониторинг заполненности диска;
- отображение uptime системы;
- вывод наиболее нагруженных процессов;
- графики изменения системных показателей;
- журнал событий и предупреждений;
- сохранение истории метрик и логов в SQLite;
- отправка уведомлений через Telegram-бота;
- запрос текущего состояния системы через команды Telegram-бота.

## Архитектура

В проекте используется слоистая архитектура. Она разделяет пользовательский интерфейс, бизнес-логику, сервисы и инфраструктурный код.

```text
Presentation Layer (WPF UI)
        ↓
Application Layer
        ↓
Services Layer
        ↓
Infrastructure Layer
        ↓
SQLite Database
```

Подробное описание архитектуры находится в [docs/architecture/architecture.md](docs/architecture/architecture.md).

## Назначение слоев

- `Sentinel.Presentation` отвечает за WPF-интерфейс, XAML-разметку, окна, страницы и ViewModel.
- `Sentinel.Application` содержит сценарии приложения, обработку данных и координацию сервисов.
- `Sentinel.Services` содержит сервисы мониторинга, уведомлений, Telegram-бота и работы с настройками.
- `Sentinel.Infrastructure` отвечает за получение системных метрик, работу с SQLite, файловой системой и внешними API.
- `Sentinel.Domain` содержит общие модели, сущности, перечисления и правила предметной области.

## База данных

SQLite используется как встроенное локальное хранилище. В базе данных сохраняются:

- история системных метрик;
- события приложения;
- предупреждения;
- настройки порогов уведомлений;
- параметры Telegram-интеграции.

Пример записи метрики:

```text
DateTime: 2026-05-13 12:30:00
MetricType: CPU
Value: 86.4
WarningLevel: High
```

## Telegram-уведомления

Telegram-бот используется для отправки предупреждений и получения краткого состояния системы по команде.

Примеры уведомлений:

- высокая загрузка процессора;
- недостаток свободной оперативной памяти;
- критическое заполнение диска.

Примеры команд:

```text
/status
/report
/help
```

## Запуск проекта

После создания решения и проектов запуск выполняется через Visual Studio или CLI:

```bash
dotnet restore
dotnet build
dotnet run --project src/Sentinel.Presentation
```

## Конфигурация

Рекомендуется хранить пользовательские настройки в локальном конфигурационном файле или защищенном хранилище Windows.

Пример настроек:

```json
{
  "Monitoring": {
    "CpuWarningPercent": 85,
    "RamWarningPercent": 90,
    "DiskWarningPercent": 90,
    "PollingIntervalSeconds": 5
  },
  "Telegram": {
    "BotToken": "YOUR_BOT_TOKEN",
    "ChatId": "YOUR_CHAT_ID"
  }
}
```

Секреты, токены и локальные файлы базы данных не должны попадать в Git.

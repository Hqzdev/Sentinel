# Sentinel

Desktop-приложение для мониторинга состояния компьютера.

## Описание проекта

Sentinel отслеживает состояние компьютера в реальном времени, отображает системные метрики в графическом интерфейсе и сохраняет пользовательские настройки локально.

Проект может использоваться для домашнего мониторинга компьютера, контроля рабочей станции и учебной демонстрации архитектуры desktop-приложений на C#.

## Основной функционал

- мониторинг загрузки CPU;
- мониторинг использования RAM;
- мониторинг активности диска;
- мониторинг сетевой активности;
- отображение uptime системы;
- вывод наиболее нагруженных процессов;
- графики изменения системных показателей;
- журнал системных событий;
- настройка порогов и интервала опроса.

## Архитектура

В проекте используется слоистая архитектура. Она разделяет пользовательский интерфейс, бизнес-логику мониторинга и инфраструктурный код.

```text
Presentation Layer (Avalonia UI)
        ↓
Core Layer
        ↓
Infrastructure Layer
        ↓
Local Settings
```

## Назначение слоев

- `SystemMonitor.App` отвечает за Avalonia-интерфейс, XAML-разметку, окна, элементы управления и ViewModel.
- `SystemMonitor.Core` содержит модели, интерфейсы и фоновый сервис мониторинга.
- `SystemMonitor.Infrastructure` отвечает за получение системных метрик и работу с локальными настройками.

## Конфигурация

Пользовательские настройки сохраняются локально в JSON-файле:

```text
%AppData%/Sentinel/settings.json
```

Пример настроек:

```json
{
  "thresholds": {
    "cpuPct": 80,
    "ramPct": 85,
    "diskReadMbs": 200,
    "diskWriteMbs": 200
  },
  "pollingIntervalSeconds": 5
}
```

Локальные файлы настроек и временные данные не должны попадать в Git.

## Запуск проекта

Запуск через CLI:

```bash
dotnet restore
dotnet build
dotnet run --project SystemMonitor.App/SystemMonitor.App.csproj
```

# SystemMonitor.App

Папка `SystemMonitor.App` отвечает за внешний вид приложения и связь интерфейса с данными.

Этот слой не должен сам читать данные из Windows API. Его задача — показать пользователю уже подготовленные данные в понятном виде.

## Главные части слоя

### Program.cs

Файл запуска приложения. Он создаёт Avalonia-приложение и передаёт управление классу `App`.

### App.axaml

Общий XAML-файл приложения. Здесь подключаются стили, тема и общие ресурсы.

### App.axaml.cs

Файл запуска главного окна. Он создаёт `MainWindow` и назначает ему `MainWindowModel`.

### Styles

Папка со стилями интерфейса.

`Theme.axaml` хранит общий дизайн: цвета, карточки, кнопки, текст и прогресс-бары.

### ViewModels

Папка с ViewModel. ViewModel хранит данные, которые отображаются на экране.

`MainWindowModel` управляет переключением экранов.

`OverviewViewModel` отвечает за общий экран с CPU, RAM и количеством процессов.

`CpuDetailViewModel` отвечает за экран подробной информации о процессоре.

`ProcessListViewModel` отвечает за список процессов.

### ViewModels/Base

Папка с базовыми классами.

`ViewModelBase` содержит общий механизм обновления интерфейса, когда меняются свойства.

### ViewModels/Converters

Папка с конвертерами для интерфейса.

`PercentToColorConverter` превращает процент нагрузки в цвет. Так интерфейс может показать нормальную, среднюю или высокую нагрузку.

### ViewModels/Views

Папка с XAML-экранами.

`MainWindow.axaml` описывает главное окно.

`OverviewView.axaml` описывает экран обзора.

`CpuDetailView.axaml` описывает экран процессора.

`ProcessListView.axaml` описывает экран процессов.

Файлы `.axaml.cs` рядом с ними нужны только для загрузки XAML. Основная логика находится во ViewModel.

## Как работает слой

1. `Program.cs` запускает приложение.
2. `App.axaml.cs` создаёт главное окно.
3. `MainWindowModel` выбирает, какой экран показывать.
4. ViewModel подготавливает данные.
5. XAML отображает эти данные пользователю.

## Простое объяснение

`SystemMonitor.App` — это лицо приложения. Пользователь видит именно этот слой: меню, карточки, таблицу процессов и показатели нагрузки.

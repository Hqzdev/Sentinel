# SystemMonitor.Tests

Папка `SystemMonitor.Tests` отвечает за проверку кода.

Тесты нужны чтобы убедиться, что сервисы возвращают данные в ожидаемом формате и не выдают явно неправильные значения.

## Главные части слоя

### Services

Папка с тестами сервисов.

`CpuMetricsServiceTests.cs` проверяет сервис процессора.

`MemoryMetricsServiceTests.cs` проверяет сервис оперативной памяти.

## Что проверяют тесты CPU

Тесты CPU проверяют:

1. Сервис создаётся без ошибки.
2. Количество логических ядер больше нуля.
3. Снимок CPU содержит время замера.
4. Общая загрузка CPU не отрицательная.
5. Загрузка каждого ядра находится в нормальном диапазоне.

## Что проверяют тесты RAM

Тесты RAM проверяют:

1. Сервис возвращает снимок памяти.
2. Объём памяти не отрицательный.
3. Использованная память не больше общей памяти.
4. Если Windows API доступен, общий объём памяти больше нуля.

## Почему есть проверка Windows

Метрики CPU и RAM в проекте читаются через Windows-механизмы.

CPU использует системные счётчики Windows.

RAM использует `kernel32.dll`.

Поэтому на macOS или Linux такие тесты не должны падать из-за платформы. Они просто не выполняют проверку Windows-специфичных сервисов.

## Простое объяснение

`SystemMonitor.Tests` — это слой проверки. Он нужен чтобы быстро увидеть, что базовые части мониторинга работают правильно.
